# rtk-search
**[View Live Site](https://tiqsif.github.io/rtk-search/)**
A lightweight, offline-first web application designed to explore *Remembering the Kanji (RTK)* cards, mnemonics, component breakdowns, and reverse lookups ("used in"). 

Hosted live on GitHub Pages.

## Features
* **Custom Mnemonics & Stories:** Displays custom story cards.
* **Interactive Cross-Linking:** Automatically parses kanji mentions inside stories and component lists, making them clickable to instantly jump to that kanji's details.
* **Component & Reverse Lookup:** Shows child primitives/components as well as every parent kanji where the character is used.
* **Fast Sidebar Search:** Filter instantly by Kanji character, Heisig keyword, or RTK frame number.

## Data Source
* Powered by a local static JSON database (`kanji_db.json`).
